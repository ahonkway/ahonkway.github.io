HarmoniRobot

Personal backup tool — single-user, private use

What this application is

HarmoniRobot is a private, single-user application. It is the personal OAuth client used by one individual (the operator) to back up data from a local AI assistant running on the operator's own computer to that same operator's own Google Drive account.

It is not a public product, not offered to the public, and has no users other than its owner.

What it does

  • Creates a compressed backup archive of the operator's local assistant data (configuration, saved procedures, conversation history, and task schedules).
  • Uploads that archive into a private folder in the operator's own Google Drive.
  • Keeps only the two most recent backups, removing older ones to conserve storage.

What data it accesses

The application only ever accesses the Google account that has explicitly authorized it — the operator's own account. It does not access any other person's data. The Google scopes it may request are used solely to perform the operator's own file management and productivity tasks:

  • drive — create and manage backup files in the operator's own Drive
  • spreadsheets — read and update the operator's own spreadsheets
  • documents — read and update the operator's own documents
  • gmail.readonly, gmail.send, gmail.modify — read, send, and organise the operator's own email on request
  • calendar — read and create the operator's own calendar events
  • contacts.readonly — read the operator's own contacts

How your data is handled

  • No data collection. No analytics, no tracking, no telemetry.
  • No third parties. Data is never transmitted anywhere except directly between the operator's computer and Google's servers.
  • No server of our own. All processing happens locally on the operator's machine. There is no intermediate backend or hosted component.
  • No selling or sharing. Google user data is never sold, rented, transferred, or disclosed to anyone.
  • Tokens stored locally only. OAuth credentials are kept in a file on the operator's own computer and are sent only to Google, to authenticate.
  • No use for advertising. Google user data is never used to serve ads or train advertising models.
