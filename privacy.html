Privacy Policy

HarmoniRobot — personal OAuth client. Effective 16 October 2026.

1. Who this policy covers

This policy covers HarmoniRobot ("the client"), a private OAuth client operated by a single individual ("the operator"). Throughout this document, "the client" means that OAuth client and "the operator" means the person who owns and runs it.

The client is for the operator's personal use only. It is not offered to the public and has no other users.

2. What data the client accesses

The client accesses Google user data only for the Google account that explicitly authorizes it — that is, the operator's own account. It does not and cannot access data belonging to anyone else.

The Google API scopes the client may request, and the purpose of each:

  • https://www.googleapis.com/auth/drive — to create, list, and delete backup archive files inside a private folder in the operator's own Google Drive. This access is required because the client is a file-management tool and must be able to see and write files, including files created outside of it.
  • https://www.googleapis.com/auth/spreadsheets — to read and update the operator's own spreadsheets.
  • https://www.googleapis.com/auth/documents — to read and update the operator's own documents.
  • https://www.googleapis.com/auth/gmail.readonly — gmail.send — gmail.modify — to read, send, and organise the operator's own email when the operator asks it to.
  • https://www.googleapis.com/auth/calendar — to read and create events in the operator's own calendar.
  • https://www.googleapis.com/auth/contacts.readonly — to read the operator's own contacts.

3. How the data is used

Data is used solely to carry out tasks the operator requests on their own computer — primarily creating local backups of the operator's own assistant data and storing them in the operator's own Google Drive. No data is used for any other purpose.

4. How the data is stored

  • All processing happens locally on the operator's own computer.
  • There is no intermediate server, backend, or hosted component belonging to the client. Data travels only between the operator's computer and Google's servers.
  • OAuth tokens are stored in a configuration file on the operator's own machine. They are transmitted only to Google, in order to authenticate.

5. Sharing and disclosure

  • Google user data is never sold, rented, traded, or transferred to any third party.
  • Google user data is never disclosed to any third party, except where strictly required by law.
  • Google user data is never used for advertising, and is never used to train, develop, or improve advertising or machine-learning models.
  • No human other than the operator reads the data.

6. Data retention and deletion

  • Backup archives are retained in the operator's own Drive under a rotation policy: only the two most recent archives are kept; older ones are automatically removed.
  • The operator can delete any backup file directly from Google Drive at any time.
  • Authorization can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately and permanently ends the client's access. Locally stored tokens can be deleted by removing the token file from the operator's computer.

7. Security

The client uses Google's standard OAuth 2.0 authorization flow. Credentials never leave the operator's computer except to authenticate with Google directly. Access is limited to the scopes listed above and can be revoked instantly by the operator.

8. Limited Use disclosure

The client's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Children

The client is not directed to children and has no users other than the operator.

10. Changes to this policy

Any changes will be published on this page with an updated effective date.
